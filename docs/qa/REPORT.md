# Проверка Metall DEMO

Дата: 2026-11-13. Статус: **Выполнено** для локальной статической демонстрации.

## Цель и результат

Подготовлена самостоятельная копия текущего интерфейса Metall с сохранённым результатом обработки чертежа и готовыми 3D-моделями. Сборка предназначена для GitHub Pages с префиксом `/Metall-DEMO/`. Для просмотра нужны только статические файлы и браузер с поддержкой Service Worker и WebGL.

Основной пример — «Вал эксцентриковый», 02.08.00761, запуск `7ea4be93-9a2b-4c9b-b50a-6943cf9048a0`, редакция 20. Полный маршрут содержит 9 операций. Сохранённое время — 177,311340347367346064 мин, стоимость производственных работ — 2 651,87 ₽ на одну деталь. Материал в денежный итог не включён. Ставки справочные.

Исходная редакция и контрольные суммы закреплены в [манифесте](../../public/demo/manifest.json). Проекции интерфейса получены офлайн из одного сохранённого состояния. Распознавание, вызовы моделей, численный расчёт и построение CAD при подготовке демо не запускались.

Проверки выполнены на Node.js 26.1.0. В workflow задан Node.js 24; удалённый CI ещё не запускался.

Браузер работал с production-сборкой на контрольном сервере, который раздаёт только файлы и отклоняет обращения к `/api/`. В раннем прерванном сценарии корзины зарегистрирован один сетевой запрос. После исправления и повторной успешной проверки корзины новых записей не появилось. Финальный сетевой снимок относится к перезагрузке сметы и не распространяется на весь журнал разработки.

Проверены все вкладки данных детали и сметы, общий маршрут и формы 9 операций, справочники, оборудование, настройки расчёта и агентов. Локальные проекты создаются, переживают перезагрузку, перемещаются в корзину и восстанавливаются. Сброс возвращает исходные проект и настройки. Попытка пересчёта показывает пояснение о демо и сохраняет исходные время и сумму.

В просмотрщиках проверены выбор грани, вращение, измерения, 31 аннотация приводного вала, разрез и скачивание STEP с проверкой SHA-256. Лайтбокс чертежа открывается с клавиатуры; масштаб проверен от 100% до 125%.

## Границы результата

- Инженерное состояние закреплено: загрузка нового чертежа, изменение геометрии и пересчёт требуют полноценного продукта.
- Приводной вал II-175 и ступенчатая деталь — самостоятельные 3D-примеры. Они не представляются моделью эксцентрикового вала.
- Сохранены ограничения номинальной модели, условное изображение резьбы, происхождение оценок и неподтверждённая применимость оборудования. Демо не подтверждает производственную приёмку, фактические тарифы или поставку материала.
- Демонстрационный справочник сокращён; счётчики соответствуют включённым строкам. История содержит только выбранный снимок.
- Профиль, проекты и настройки агентов сохраняются в браузере конкретного посетителя. Общего хранилища нет.
- GitHub Pages workflow подготовлен с ручным запуском. Публикация и push не выполнялись; размещение на GitHub Pages пока не проверено.
