# Обновление интерфейса Metall DEMO

Дата: 2026-11-13. Статус: **Выполнено** в локальном интерфейсном контуре.

## Результат

В полном маршруте каждый размер отображается вместе с местом на чертеже, допуском и шероховатостью. Записи сохраняют отдельные привязки; на узких экранах источник и значение располагаются друг под другом.

На страницах сметы и маршрута восстановлено плавающее окно чертежа. Оно располагается под навигацией документа и остаётся в рабочей области при прокрутке. Документы прокручиваются внутри приложения под верхней панелью. Закрытие окна возвращает клавиатурный фокус на ссылку текущего документа, когда миниатюра уже вне видимой области.

Перенесены пять файлов интерфейса из Metall. Основа UI — коммит `eced9789`, включая текущее содержимое рабочих файлов исправления окна и прокрутки. Нормализованные контрольные суммы и состав изменений записаны в [source-sync.json](source-sync.json). В демо сохранён дополнительный импорт общего CSS, необходимый для прямого открытия страниц с отложенной загрузкой.

## Проверка

- `npm run lint`, `npm run test:demo`, `npm run build` — успешно.
- Все пять файлов соответствуют исходному UI с единственной указанной адаптацией CSS.
- Восемь адресных браузерных проверок — успешно; протокол: [browser-check.json](browser-check.json).
- Проверены 57 пар размеров на широком экране; источник и значение выровнены по верхней границе.
- При 390 и 320 px сохранены все 57 пар, переполнения страницы нет. При 390 px пары располагаются вертикально, окно чертежа автоматически не открывается.
- На страницах маршрута и сметы окно чертежа отображается; прокрутка остаётся внутри рабочей области.
- Проверены возврат фокуса без скачка прокрутки, перемещение и изменение размера окна стрелками клавиатуры.
- Сохранены редакция 20, время 177,311 мин и сумма 2 651,87 ₽. Все 18 артефактов соответствуют прежним контрольным суммам; каталог `public/` и исходники 3D-просмотрщика не изменены.
- Во время адресной браузерной проверки контрольный статический сервер не получил новых обращений к API. Модели и бэкенд не запускались.
