# Metall DEMO

Статическая демонстрация рабочего интерфейса Metall для ознакомления с результатом обработки чертежа. Сайт работает в браузере: backend, ключи API, Codex и CAD-движок для просмотра не нужны.

## Запуск

Рекомендуется Node.js 24; также поддерживается ветка Node.js 22 начиная с 22.13. В GitHub Actions используется Node.js 24.

```sh
npm ci
npm run dev
```

Открыть `http://127.0.0.1:5188/Metall-DEMO/`.

Проверка готовой сборки на сервере, который раздаёт только файлы:

```sh
npm run build
npm run preview:static
```

Адрес: `http://127.0.0.1:4189/Metall-DEMO/`.

Приложение использует Service Worker. Для него нужен HTTPS либо локальный HTTP на localhost/127.0.0.1. Открытие `index.html` через `file://` не поддерживается. В браузер загружаются статические ресурсы сайта; обязательных внешних шрифтов и сервисов нет.

## Содержание

- Демонстрационный проект с распознанным чертежом «Вал эксцентриковый», обозначение 02.08.00761.
- Описание, технический паспорт, заготовка, свойства материала, сохранённые уточнения и предварительный маршрут.
- Полный маршрут: девять операций, установы, переходы, режимы, объёмы, время и расчётные формы.
- Смета производственных работ: 2 651,87 ₽ за одну деталь, полное расчётное время 177,311 мин. Материал не входит в денежный итог. Ставки являются справочными расчётными значениями.
- Печатная форма сметы и печать маршрута средствами браузера.
- Два самостоятельных 3D-примера: приводной вал II-175 и ступенчатая деталь. Доступны вращение, виды, выбор граней, размеры, разрезы и скачивание STEP. Эти модели не являются моделью эксцентрикового вала.
- Сохранённые карточки оборудования, конфигуратор и ограниченный демонстрационный набор НСИ. Счётчики справочных строк соответствуют фактически включённым данным.

Проекты можно создавать, переносить в корзину и восстанавливать. Профиль оператора и настройки агентов меняются локально в браузере. Кнопка «Сбросить демо» возвращает исходное состояние, не затрагивая данные других приложений на том же домене.

Инженерные данные и результаты расчёта зафиксированы. Попытка изменить количество, геометрию, расчётные ставки или запустить обработку открывает пояснение о демонстрационном режиме. Сохранённые суммы и геометрия остаются согласованными. Демо не выполняет распознавание загруженного посетителем документа, новые построения 3D или вызовы моделей.

## Устройство

`src/` содержит компоненты и оформление исходного Metall. Страницы загружаются по мере переходов. Отличия демо сосредоточены в `src/demo/`, запуске приложения, маршрутизаторе и адресах файлов. MSW отвечает на обращения UI к API внутри браузера. Неподдержанные команды получают явный отказ; пересылки запросов на реальный сервис нет.

`public/demo/responses.json` содержит согласованные ответы для интерфейса. Полный маршрут, таблица сметы, печатная форма, уточнения и готовность расчёта получены офлайн из одного состояния. В публичный набор не включены нативные трейсы, промпты, сессии, ключи и базы данных.

`public/models/` содержит готовые STEP, сетки, геометрическую инспекцию и аннотации. Исходники просмотрщика лежат в `viewer/`; `npm run build` автоматически подготавливает статические просмотрщики и локальную копию Three.js. Операции OCCT при сборке и просмотре не выполняются. Ограничения номинальной модели и условной резьбы сохранены в просмотрщике.

`public/demo/manifest.json` закрепляет исходный коммит, запуск, редакцию, результаты и контрольные суммы артефактов. Название демонстрационного проекта задано отдельно от исходного TEST-проекта. Полнота расчётного примера не подтверждает фактические тарифы предприятия, поставку или производственную пригодность оборудования.

## Проверка

```sh
npm run lint
npm run test:demo
npm run build
npm audit
```

Проверка данных сверяет редакции, число операций, время, суммы документа, контрольные суммы, реальные счётчики строк и соответствие STEP размерным аннотациям. Результаты браузерной проверки и снимки размещены в `docs/qa/`.

## GitHub Pages

Настроен префикс `/Metall-DEMO/` и HashRouter. Внутренние адреса имеют вид `/Metall-DEMO/#/runs/...`; они открываются напрямую и после перезагрузки.

Workflow `Check static demo` проверяет push и pull request. Workflow `Publish GitHub Pages` запускается вручную через Actions. Автоматической публикации при push нет. Для размещения в Settings → Pages выбирается источник GitHub Actions, затем вручную запускается публикация подготовленной версии.

## Обновление исходных данных

Обычные запуск и сборка полностью самостоятельны. Репозиторий Metall и Python нужны только для явного обновления демонстрационного комплекта:

```powershell
& ../metall-dev-2/mvp/.venv/Scripts/python.exe scripts/export-fixtures.py --source ../metall-dev-2
npm run test:demo
npm run build
```

Экспорт читает сохранённые свидетельства и вызывает только чистые функции проекции данных. Он не запускает сервисы, распознавание, модели или численный движок. Обновление на другую редакцию требует повторной сверки данных и интерфейса.

Исходные материалы: [Metall](https://github.com/Lotargo/metall-dev-2), результаты D348–D354 от 13.11.2026. Полные идентификаторы находятся в манифесте.
