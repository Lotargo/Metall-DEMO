# Metall DEMO

Статическая демонстрация рабочего интерфейса Metall для ознакомления с результатом обработки чертежа. Сайт работает в браузере: backend, ключи API, Codex и CAD-движок для просмотра не нужны.

## Запуск

Рекомендуется Node.js 24; также поддерживается ветка Node.js 22 начиная с 22.13. В GitHub Actions используется Node.js 24.

```sh
npm ci
npm run dev
```

Открыть `http://127.0.0.1:5188/Metall-DEMO/`.

Проверка готовой сборки на сервере, который раздаёт только файлы:

```sh
npm run build
npm run preview:static
```

Адрес: `http://127.0.0.1:4189/Metall-DEMO/`.

Приложение использует Service Worker. Для него нужен HTTPS либо локальный HTTP на localhost/127.0.0.1. Открытие `index.html` через `file://` не поддерживается. В браузер загружаются статические ресурсы сайта; обязательных внешних шрифтов и сервисов нет.

## Содержание

- Главная страница открывает расчёт вала V-560.110.00.10. Доступны все вкладки рабочего пространства и окно «Ход обработки» с сохранёнными этапами.
- Чертёж PDF, интерактивная 3D-модель с размерами, технический паспорт и две редакции STEP в истории.
- Заготовка, полный маршрут, смета и основания расчёта по материалу, объёмам, времени и стоимости.
- Ориентировочное время на одну деталь составляет 885,60–1 979,27 мин. Стоимость оценённых работ составляет 6 878,50–16 039,33 ₽. В смете отмечены пять работ без ставки.
- Печатные формы сметы, маршрута и оснований доступны для печати и скачивания PDF. Маршрут с расчётом и основания также можно скачать в Markdown.
- Доступны парк оборудования, конфигуратор и демонстрационные данные справочника НСИ.

Проекты можно создавать, переносить в корзину и восстанавливать. Профиль оператора и настройки агентов меняются локально в браузере. Кнопка «Сбросить демо» возвращает исходное состояние, не затрагивая данные других приложений на том же домене.

Инженерные данные доступны для просмотра. Демо использует сохранённые суммы и геометрию, запуск новой обработки доступен в полной версии Metall.

## Устройство

`src/` содержит компоненты и оформление исходного Metall. Страницы загружаются по мере переходов. Отличия демо сосредоточены в `src/demo/`, запуске приложения, маршрутизаторе и адресах файлов. MSW отвечает на обращения UI к API внутри браузера. Неподдержанные команды получают явный отказ; пересылки запросов на реальный сервис нет.

`public/demo/responses.json` содержит согласованные ответы для интерфейса. `public/demo/assets.json` связывает ссылки из сохранённого расчёта с файлами под префиксом GitHub Pages. В набор входят только данные и артефакты, используемые для просмотра и скачивания.

`public/models/` содержит готовые STEP, сетки, геометрическую инспекцию и аннотации. Исходники просмотрщика лежат в `viewer/`; `npm run build` автоматически подготавливает статические просмотрщики и локальную копию Three.js. Операции OCCT при сборке и просмотре не выполняются. Ограничения номинальной модели и условной резьбы сохранены в просмотрщике.

`public/demo/manifest.json` закрепляет запуск, редакции, результаты и контрольные суммы артефактов. Название демонстрационного проекта задано отдельно. Результаты относятся к сохранённому предварительному сценарию.

## Проверка

```sh
npm run lint
npm run test:demo
npm run build
npm audit
```

Проверка сверяет время, сумму оценённых работ, редакции моделей, контрольные суммы, счётчики строк и связь STEP с размерными аннотациями.

## GitHub Pages

Настроен префикс `/Metall-DEMO/` и HashRouter. Внутренние адреса имеют вид `/Metall-DEMO/#/runs/...`; они открываются напрямую и после перезагрузки.

Workflow `Check static demo` проверяет push и pull request. Workflow `Publish GitHub Pages` запускается вручную через Actions. Автоматической публикации при push нет. Для размещения в Settings → Pages выбирается источник GitHub Actions, затем вручную запускается публикация подготовленной версии.

## Обновление исходных данных

Обычные запуск и сборка самостоятельны. Экспорт нового завершённого примера читает готовый расчёт с локального сервера Metall.

```powershell
python scripts/export-fixtures.py --run 6c64f6c9-b4ec-416e-983d-80c2106e60dd
npm run build
```

Экспорт читает сохранённые результаты запросами GET. При обновлении примера укажите новый `DEMO_RUN_ID` в `src/demo/config.ts`, выгрузите печатные формы из нового состояния и обновите их контрольные суммы в манифесте. После этого запустите `npm run test:demo` и пересоберите сайт.
